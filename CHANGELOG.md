# CHANGELOG.md - Project History

## [2.4.0] - Profile Bust Navigation Icon Update

### Added
- Updated the 4th top navigation pill tab in `PlantListScreen.kt` to use the profile bust icon (`Icons.Default.Person`) and `"Profile"` label.
- Pushed live to GitHub repository `https://github.com/wcsurface/StillLeaf`.

## [2.3.0] - Immersive System Navigation Bar Hiding

### Added
- Configured sticky immersive mode in `Theme.kt` using `WindowInsetsCompat.Type.navigationBars()` to hide system navigation buttons (`<`, `O`, `|||`).
- Matched system navigation bar color to Warm Ivory (`#F7F4E9`).
- Pushed live to GitHub repository `https://github.com/wcsurface/StillLeaf`.

## [2.2.0] - Warm Ivory Theme Enforcement

### Fixed
- Fixed issue where Android system dark mode overridden application background to dark green.
- Updated `StillLeafTheme` and `themes.xml` to strictly enforce the Warm Ivory (`#F7F4E9`) brand background on all devices regardless of system dark mode settings.
- Pushed live to GitHub repository `https://github.com/wcsurface/StillLeaf`.
